# Data manifest

Nothing under `data/` is committed except this file. Everything here is either
too large for git, derived and reproducible, or licensed such that it should be
distributed from the Hub instead.

| Artifact | Path | Committed? | Where it lives |
|---|---|---|---|
| OpenStax PDFs | `data/raw/` | No | Fetched by `ragft.corpus.download`; SHA-256 + URLs + page counts recorded in `data/raw/manifest.json` |
| Parsed sections | `data/corpus/` | No | Regenerated by `ragft.corpus.parse` |
| Synthetic QA (train/val) | `data/qa/` | No | Published to the HF Hub; stats in `reports/dataset_card.md` |
| Frozen eval set | `data/eval/` | No | Published to the HF Hub; hashed in `configs/eval/frozen.lock` |
| Qdrant index | `data/index/` | No | Rebuilt by `ragft.retrieval.index` |

Hub links are added as each artifact is published.
