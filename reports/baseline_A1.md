# Baseline: A1 (base model, no retrieval)

Generated by `ragft.eval.report_baseline`. **Do not hand-edit.**

300 gold items. This arm is the control the other three are read against —
without it, "RAG beats fine-tuning" has no reference point.

## Citation grounding — judge-free

Scored at four increasingly strict levels, because one number hides the finding.

| Level | Rate |
|---|---|
| Produces a citation | 98.3% |
| Cites a section that **exists** | 98.0% |
| Cites the **correct** section | **1.3%** |
| Page inside that section | **0.3%** |
| Carries the CC BY attribution | 98.3% |
| **Fabrication rate** (real section, wrong one) | **96.7%** |

The base model has learned the *shape* of an OpenStax citation — plausible
chapter.section numbering, a plausible page, the licence suffix — with almost no
content mapping underneath. Confident, well-formatted, and fabricated.

This retroactively justifies the page-level citation format adopted from
VidyaRAG. A section-level format would have scored
98% here and hidden the entire phenomenon.

| Valid (Answer + Why) | 93.3% |

⚠️ Read as a **manipulation check**, not a result. The high rate here matters for
a different reason: it shows the base arm complies with the format when given
few-shot examples, so a later "fine-tuning wins on format" claim cannot be an
artefact of the baseline never having been asked (threat 2).

## What is NOT here

Judged accuracy is deliberately absent from the headline. The judge is a local
9.6 GB model and its agreement with human labels has not been established yet.
Until Cohen's kappa is measured, every number above that needed a judge is
provisional — and every number that did not is not.
